# Wild Stories TV Website

Static website package for Wild Stories TV and the Wild Crew community.

## Preview Locally

1. Unzip the website package.
2. Keep `index.html` and the `assets/` folder together in the same folder.
3. Open `index.html` in a browser.

The site has no backend, no build step, and no React dependency.

## Publishing Notes

- Replace `https://your-website-url.com/` in the Open Graph tags after the final domain is known.
- Replace the `og:image` URL with the fully hosted image URL after publishing.
- Replace featured story card links with exact Facebook Reel URLs when those URLs are available.
- Keep the Facebook Page link as `https://www.facebook.com/wildstoriestv/`.
- Keep the Wild Crew Messenger Channel link as `https://www.messenger.com/channel/wildstoriestv`.
- Keep the email link as `wildstoriestvlive@gmail.com`.
